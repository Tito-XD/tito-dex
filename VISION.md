# TitoDex Vision

TitoDex should feel like a small trainer device that helps a player return to a
Pokémon journey immediately. It is warm, local-first and aware of the selected
game—not a general wiki or competitive simulator.

The product favors playthrough utility: current save progress, party context,
nearby encounters, version-accurate evolution routes and compact reference
tools. Data gaps are shown honestly, and user saves stay on the device.

Primary target: Android phones and compact RG handhelds. Web is a supported
preview surface; iOS source shares the codebase but distribution is not active.
