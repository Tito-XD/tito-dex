# TitoDex Product

## Audience

Players returning to older or current Pokémon playthroughs who want one compact
Chinese companion for save progress, team management, locations, Pokédex data
and lightweight battle checks.

## Core jobs

1. Resume the selected game quickly.
2. Understand the current party and save progress.
3. Find version-appropriate Pokémon, locations, evolution routes and reference data.
4. Keep useful data available offline on handheld hardware.

## Scope

TitoDex ships a 1–1025 Pokédex, form-aware media and obtain data, save-aware
journeys, a location dex, reference catalogs and quick battle estimates. It
does not aim to reproduce a community wiki, interactive world map, cloud save
service or competitive simulator.

Feature priority is: journey value → correctness and offline reliability →
polish. New breadth should not weaken startup speed, source attribution or the
honest handling of unknown data.
