# TitoDex 图鉴 · 微信小程序原型

基于 TitoDex v20 真实数据（PokeAPI + 52poke 中文图鉴文本）的原生微信小程序原型。

## 预览覆盖范围

WorkBuddy 小程序产物卡片提供的是**内置预览**，覆盖以下逻辑：

- 全国图鉴 1025 条，双列卡片，编号 / 中文名 / 英文名 / 属性 / 远程官方立绘
- 搜索：中文名、英文名（忽略大小写）、编号（支持 `25` / `025` / `#025`）
- 世代 1-9 × 18 属性交集筛选，含结果数量、重置、无结果反馈
- 每页加载 40 条，触底加载更多（避免一次渲染 1025 张图）
- 详情页：全部条目有基础信息；17 个代表条目展示种族值（总和动态计算）、特性（含隐藏标记）、可展开的版本图鉴描述、结构化进化链（亲密度 / 进化石 / 地点升级等按结构化条件翻译，未知条件显示原值）
- 身高单位 dm/10 = 米；体重 hg/10 = 千克
- 返回列表保留搜索与筛选状态（navigateTo 页面栈原生行为）
- 图片加载失败显示占位

## 尚未验证 / 边界

- **微信真机未验证**：原型未经微信开发者工具真机调试与上架审核流程。
- 图片为远程加载（PokeAPI sprites 固定版本地址），**不承诺国内网络加载稳定性**；正式版需通过云开发图片分发并真机测试。
- 内置预览不能完全等同微信运行时行为，个别原生组件表现可能有差异。

## 数据

- `data/index.js`：1025 条索引（自动生成自 `input/pokemon-index.json`）
- `data/details.js`：17 条详细数据（自动生成自 `input/pokemon-details.json`）
- 原型无后端、无登录、无云服务；未创建试用小程序、未绑定账号、未发布。

## 自检

`verify.cjs` 为可运行的自检脚本（10 组共 42 项检查），覆盖：

- 数据完整性（1025 条索引、17 条详情、属性映射、图片地址）
- 搜索与筛选逻辑、单位换算（dm→m、hg→kg）
- 种族值总和、特性中文、版本描述、结构化进化链（未知条件显示原值）
- 详情页 detail.js 逻辑与 detail.wxml 绑定、README 与工程配置

运行：`node ../verify.cjs`，全部通过输出 `通过 42 / 42`，任一失败退出码为 1。

## 验收修正

- 进化地点与成长速度使用 TitoDex 的现有中文词表，友好度与亲密度分开显示。
- 伊布等进化分支写明父节点与目标，重复条件合并。
- 15 个条目的分类字段来自其他语言；原型先隐藏这些分类，保留中文名称与已知数据。
- 孵化显示源数据中的周期数；不推算跨游戏版本的固定步数。
