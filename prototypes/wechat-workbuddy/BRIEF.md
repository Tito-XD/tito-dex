# TitoDex 微信小程序原型

当前只生成原型与 WorkBuddy 预览。用户未注册微信小程序账号。不要创建试用小程序、绑定账号、部署云服务、提交审核、发布或购买。

## 来源与边界
- fixtures/pokemon-index.json：v20 真实全国图鉴索引，1025 条，id 1-1025。
- fixtures/pokemon-details.json：17 个代表条目的真实详细数据，以 id 字符串为键。
- fixtures/data-version.json：来源版本与下载记录。
- 只读取 fixtures/ 和本文件。source-cache/ 是原始抓取缓存，包含内部链接，不要读取或复制。不要读取其他目录的项目、账号或凭据。
- 首版不接后端。索引为原型展示数据；不开发离线包下载/管理。

## 功能
创建原生微信小程序，使用 WorkBuddy 小程序产物卡片提供内置预览；不要只交付普通网页。
1. 全国图鉴：清晰的双列卡片，编号、中文名、英文名、属性、真实图像。
2. 搜索：中文名、英文名（忽略大小写）、编号（支持 25 / 025 / #025）。
3. 世代 1-9 和 18 种属性交集筛选，显示结果数量、重置、无结果反馈。
4. 每次加载 40 个或类似合理数量，触底加载/加载更多，避免同时渲染 1025 图片。
5. 详情：全部条目都有基础信息；17 个代表条目展示种族值、特性、图鉴描述、进化链。缺少扩展数据的条目只展示已知信息并提示更多详情稍后接入在线版，绝不填造假数据或零值。
6. 使用微信原生 navigateTo、默认返回与页面动画。返回列表保留搜索和筛选，不做自定义路由动画。
7. 简单的关于页：原型版本、来源与覆盖说明。

## 数据准确性
- index generation 是数字；types 是英文 slug 数组。提供准确的 18 种属性中文映射。
- 身高 heightDm / 10 为米；体重 weightHg / 10 为千克。
- baseStats keys: hp, attack, defense, specialAttack, specialDefense, speed；总和动态计算。
- 详情特性已带中文名/中文描述，不要让模型重写。
- flavorEntries 使用真实 text 和版本 labelZh；可以折叠或分版本选择。
- evolutionChain 是树，children 含 triggers；必须使用结构化条件而不是仅有 triggerZh（后者可能不完整）。例如皮丘亲密度 220、皮卡丘雷之石。分支需保留；未知条件显示原值，禁止猜测。
- 图像地址是公开的 PokeAPI sprites 固定版本官方立绘，用远程 image 加载，显示加载失败占位；本次不下载/打包图片。
- 原型不承诺国内网络稳定性，正式版需通过云开发图片分发与真机测试。

## 视觉
简体中文。TitoDex 的蓝灰、奶油、深蓝色：#2f4361 / #7b91a6 / #afc7da / #f3e4b3 / #fff7e6 / #f7d977。细边框、轻圆角、充足留白，阅读优先。顶部搜索与筛选容易触达，插画占卡片主要面积，不使用 emoji 代替宝可梦图片。尽量用小程序原生组件，不复刻 Flutter 动画或设备壳。

## 本阶段不包含
登录/手机号、支付、存档导入与同步、读取本地/外部文件、离线包、companion、AI、云服务开通、试用小程序创建、账号授权或正式发布。

## 输出
将生成代码放在 miniprogram/，保留 fixtures/。提供原生小程序源码和 project.config.json（无正式 appid，使用开发/游客值）。预览应有微信小程序产物卡片。README 清晰写明预览覆盖、微信真机仍未验证。检查搜索、筛选、单位、返回状态、无结果、图片失败与缺少扩展详情。
