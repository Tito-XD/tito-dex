# TitoDex 微信小程序原型

2026-10-01，使用 WorkBuddy 5.7.3 创建的原生微信小程序。当前用于界面与交互验收，尚未绑定微信小程序账号或发布。

## 打开原型

在 WorkBuddy 中打开「创建 TitoDex 图鉴小程序原型」任务，点击「TitoDex 图鉴原型」产物卡片。已更新同一个应用的修正版预览。内置预览依赖 WorkBuddy 的本地预览服务，关闭服务后临时预览地址不能使用。

## 覆盖

- 1025 条全国图鉴：中文名、英文名、编号搜索，世代与属性交集筛选，每次加载 40 条，另提供显式「加载更多」按钮。
- 17 个代表条目：种族值、特性、版本描述、进化链。其余条目只提供基础信息。
- 使用微信原生页面栈与返回；图片按需在线加载，失败时显示占位。
- 不包含存档同步、文件读取、离线包、companion 或 AI。

## 文件

- `miniprogram/`：可导入微信开发者工具的原生源码，AppID 为游客值。
- `fixtures/`：精简的 v20 原型展示数据、中文词表与来源哈希；不含 CDN 内部链接。
- `verify.cjs`：行为检查，执行 `node verify.cjs`，目前 42 项通过。

## 已验证与后续

已对代码中的搜索、筛选、分页、导航状态、图片失败、17 条详情的单位与种族值、数据缺失状态、进化名称执行行为检查。内置预览已实际点通编号搜索、详情、返回保留、无结果与重置。

微信真机运行、服务器/图片域名配置、国内网络加载表现、云开发接入和微信审核仍需账号准备后单独验证。图片暂使用公开 PokeAPI 固定版本地址，不代表最终生产分发方式。未创建试用小程序、开通云服务或购买。

来源与许可见 miniprogram/README.md。本目录是独立原型，不参与 Flutter 构建，尚未提交或推送。
