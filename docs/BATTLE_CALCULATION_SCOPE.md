# 对战工具计算范围

单只与整队伤害共同使用 `estimatePartyMove`，队员编辑仅更改本次工具会话。配招选择先按当前游戏的 learnset 筛选，再进入计算。招式威力、属性、分类和接触/先制/群攻标记按第四至第九世代读取，不能直接使用现代图鉴的威力替代历史数据。

## 本轮修正

- 修正第四、第五世代钢属性对幽灵、恶的抗性：关系表按进攻属性索引，不能修改钢属性的进攻关系。
- 胆量只绕过幽灵这一属性的免疫，保留另一属性的抗性或弱点；破格只忽略可被忽略的防守特性。
- 太晶、本系、适应力分别叠加；整队也传入进攻方太晶状态。皮肤类特性转换属性、提高威力，但不会凭空赋予本系加成。
- 精神冲击、精神击破、神秘之剑使用特攻对物防；扑击使用自身防御；欺诈使用目标攻击。冷冻干燥仅改变对水属性的关系。
- 气象球随天气改变属性和威力；硬撑按异常状态加倍，灼伤减伤的例外从第六世代起生效。
- 地球上投、黑夜魔影、龙之怒、音爆按固定伤害处理，保留免疫，不再乘本系或道具倍率。
- 自动读取接触标记，区分毛茸茸与物理/特殊分类；防弹、防音和精神场地先制免疫单独处理。
- 场地检查是否接地和世代倍率。青草场地下地震/重踏减威力；沙暴岩石特防、下雪冰属性物防分别处理。
- 灼伤在伤害阶段减半，避免等价成攻击减半而漏掉基础伤害常数；不同阶段分步取整。
- 能力展示区按世代区分麻痹速度修正（第七世代前为 1/4，之后为 1/2），毅力不再同时承受灼伤攻击减半；脱壳忍者的基础 HP 为 1。

## 明确边界

这是快速估算器，尚不是完整对战模拟器。

- 连击、反击、浮动威力、回合历史、特殊招式回调，以及尚未实现的特性条件会阻止输出数值并显示原因。残血特性、毅力之外的部分异常联动、星晶首击状态、未知携带道具等不能默默略过。
- 目前输入包含无异常、灼伤、麻痹；尚未模拟能力等级、替身、守住、当前剩余 HP、双打队友特性、完整回合流程、Z 招式或极巨化。
- 仍有世代细节和修正链取整的近似，不能保证与卡带逐点一致。显示的一击击倒判断是在这些已声明假设下的估算。
- 双打群攻开关仅给具有群攻标记的招式应用群攻修正；并非完整的双打场景建模。
- 特性元数据以现代实现为保守筛查依据，不替代完整的历史特性数据库。没有收录的组合应继续加明确规则和回归用例，不能直接放行通用公式。

## 数据来源与重建

招式历史表和特性条件分类来自 [Pokémon Showdown](https://github.com/smogon/pokemon-showdown/tree/2ddfa0476f8207e12e204b1c69f7c7683b17633c)，固定修订 `2ddfa0476f8207e12e204b1c69f7c7683b17633c`，使用 MIT 许可，全文保留在 `docs/licenses/pokemon-showdown.txt`。规则核对参考 [Smogon Damage Calculator](https://github.com/smogon/damage-calc/tree/master/calc/src/mechanics)。

将该修订的 `data/moves.ts`、`data/abilities.ts`、`data/mods/gen4/moves.ts` 至 `gen8/moves.ts` 下载到一个工作目录，分别命名为 `data-moves.ts`、`data-abilities.ts`、`data-mods-genN-moves.ts`，同时保存 `LICENSE` 和包含修订号的 `revision.txt`。运行：

```text
python tools/build_battle_move_rules.py <工作目录>
```

脚本仅读取字面字段与回调存在性，不执行上游代码；产出 `flutter/lib/features/companion/battle_rule_data.dart`。回归覆盖历史威力、特殊取值、属性组合、太晶、免疫、未知条件阻断，以及单只/整队共享入口。

## 界面切换

两个选择栏共用胶囊组件，视觉底栏缩薄，触摸高度保留至少 44。选中背景在 280ms 内滑动，工具和分析范围切换配合 220ms 淡入；输入与滚动状态保留，并遵循减少动态效果设置。
