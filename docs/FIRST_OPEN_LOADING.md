# 首次打开与加载检查（2026-09-08，v0.9.16）

本轮是源代码检查与 Flutter 回归验证，不是 Android 真机帧率报告。首次打开的卡顿可能来自读取、解析、组件布局或图片解码；加加载图标本身不能解决 UI 线程占用。

| 页面 / 部分 | 首次需要的工作 | 处理方式 |
| --- | --- | --- |
| 图鉴列表、搜索、筛选 | 摘要、筛选目录、地区与招式等索引 | 保留仓库缓存；目录 JSON 和模型构建均在 isolate；小读取不闪加载图标 |
| 宝可梦详情、队伍、进化链 | 每只详情、招式字典、图片 | 离线招式字典合并并发读取并复用结果，文件变化或清空后失效；队伍现有名字和精灵图先显示 |
| 地点图鉴 | 地点索引、各版本地点合并、摘要 | 大 JSON 和地点模型在后台解析；地点卡片改为随滚动构建，避免首屏布局全部卡片 |
| 招式、特性、道具与其他资料 | 本地 / 在线资料索引；道具与招式版本矩阵 | 大 JSON 后台解析；离线 object-shaped 资料不再先按数组失败后重读；保留资料列表的分批展示 |
| 战斗计算 | 属性关系；四个工具的控件 | 首次只挂载选中的工具，访问后保留输入；隐藏工具停止 ticker；并发属性读取合并，命中内存缓存直接展示 |
| 剪影问答、同行选择 | 候选摘要、媒体目录、图片 | 共用数据解码优化；真正等待时使用延迟加载提示 |
| 首页、队伍、旅程 | 本地旅程、成员详情、进度提示、辅助资料 | 保留可以立即展示的内容，辅助信息补齐，不额外加入整页等待 |
| 设置、素材管理、资料包 | 设置读取、文件统计、目录或网络下载 | 轻量设置无需额外动效；共用区块加载提示；有真实进度的下载仍显示百分比 |
| 在线插画、版本图片、周年图片 | 网络获取和图片首帧解码 | 普通小图使用静态占位；已有球形图片加载位与显式媒体下载等待超过 160 ms 后显示球 |
| Ask TitoDex | 历史记录、网络检索和回答流 | 保留已有语义进度与回答流动效；它们不属于本次图片 / 资料加载球的 shimmer |

## 加载反馈

- 浅白色精灵球固定在原地旋转，颜色和透明度恒定，无 shimmer、脉冲或横向位移。浅色卡片加轻描边帮助辨认。
- 共用区块、慢图片等待超过 160 ms 才挂载加载动效；数据一到立即展示，不为让用户看完动画而延迟。
- 普通图鉴小图保留静态占位，不为每个格子创建动画。首次空图鉴保留网格轮廓，只放一个加载球。
- 创建仓库对象时不再立即请求平台文件目录，仅真正读写时初始化存储路径，纯索引查询和未打开的工具不会提前触发文件服务。
- 支持系统减少动态效果；不可见工具停止 ticker。下载百分比不延迟。
- 保留此前入场动画稳定的组件层级，动画结束不销毁并重建内容。
